# C/C++标准输入输出

在了解具体的输入输出函数前，我们要清楚C标准的输入输出和C++标准的输入输出是不同的，虽然都可以用，但我们可以以此来分类

## 输入流

### C标准

需要头文件:
```c
#include<stdio.h>
```
**输入原理**：标准输入流 **stdin** 是一种行缓冲I/O，可以理解为一段存在于操作系统内存中的缓冲区

当我们从键盘键入字符时，它们首先被存在键盘硬件设备自身的缓存中，只有当我们输入换行符时，操作系统才会将键盘缓存里的内容同步到 **stdin** 的输入缓存区中

所有从stdin读取数据的函数都是从这个缓冲区中读取数据，当缓冲区中没有内容时，读取数据的函数就会堵塞（等待输入）

#### 1. scanf() —— 按照特定格式从stdin中读取

```c
char s[10];
int a;
scanf("%s %d", s, &a);    // 传入的是变量的地址
```

**ta如何处理空白字符（空格、tab、换行符）**：

- 缓冲区开头：直到有第一个非空白字符才认为是第一个数据
- 缓冲区中间：一旦遇到空白字符（非换行符），视为读取完毕一次，空白字符残留在缓冲区
- 缓冲区末端：遇到换行符，读取结束，换行符残留在缓冲区

**格式控制符**

格式控制符只会读取正确类型的变量，如果输入类型或格式不匹配，就会使读取中断，后续不会读取任何变量

|格式控制符 |类型输入    |参数类型       |
|:-:|:-------:|:--------:|
|%d |十进制整数    |int       |
|%u |无符号十进制整数 |unsigned int|
|%o |八进制整数    |int       |
|%x |十六进制整数   |int       |
|%f |单精度浮点数   |float     |
|%lf|双精度浮点数   |double    |
|%c |字符（含空白字符）|char      |
|%s |字符串      |char *    |

注意：**%c** 会读取所有空白字符，包括缓冲区开头的空白字符；用 **%%** 表示‘%’。
scanf()的读取没有边界，所以并不安全，C11引入了安全输入**scanf_s()**。

#### 2. gets() —— 按下回车键时，从stdin读取一行

```c
char s[10];
gets(s);
```

**ta如何处理空白字符**：

- 除换行符外的空白字符均会被读取
- 按下回车键，缓冲区末尾的换行符被丢弃，缓冲区无残留的换行符

注意：**gets()** 没有读取上限，因从容易造成数组越界，C11引入了**gets_s()**

#### 3. fgets() —— 从指定输入流（stdin、文件流）读取一行

```
// 读取文件流
char s[100];
memset(s, 0, sizeof(s));
int i = 1;
 
FILE *fp = fopen("test.txt", "r");
if (fp == NULL) {
    printf("Failed to Open File!\n");
    exit(1);
}
 
while (fgets(s, sizeof(s), fp) != NULL)
    printf("line%d [len %d]: %s", i++, strlen(s), s);
 
fclose(fp);
```

```c
// 读取stdin
char s[100];
memset(s, 0, sizeof(s));
int i = 1;
while (fgets(s, sizeof(s), stdin) != NULL)
    printf("line%d [len %d]: %s", i++, strlen(s), s);
```

**ta如何处理空白字符**：

- 除换行符外的空白字符均会被读取
- 按下回车键，缓冲区末尾的换行符也被读取，字符串末尾会有换行符

注意：**fgets()** 第二个参数是读取的最大长度，函数在读到 n-1 个字符（包括末尾的换行符）就会停止，并在结尾加上一个结束符 **\0**

#### 4. fgetc() & getc() —— 从指定输入流（stdin、文件流）读取一个字符

两个函数完全等效，**getc()** 由 **fgetc()** 宏定义而来，不同于上文的 **fgets()** 和 **gets()**

```c
char a, b;
a = fgetc(stdin);
b = getc(stdin);
```

**ta如何处理空白字符**：

- 所有空白字符，无论在缓冲区的开头、中间还是末端，都会被读取
- 如果一次性输入多个字符，只会读取第一个字符，其他字符全部留在缓冲区

#### 5. getchar() —— 从stdin读取一个字符

实际上也是从 **fgetc()** 宏定义而来，默认输入流为 **stdin**

```c
char a;
a = getchar();
```

注意：**getchar()** 常用于清理缓冲区开头残留的换行符，直接调用 **getchar()** 即可

### C++标准

需要头文件:
```cpp
#include<iostream>
```

#### 1. cin

**cin** 是C++的标准输入流对象，是 **istream** 的一个对象实例

**cin** 有自己的缓冲区，但默认情况下与 **stdin** 同步（所以C标准和C++标准可以混用）

**cin** 与 **stdin** 一样是行缓冲，遇到换行符才会把数据同步到缓冲区

##### 1.1 cin >>

```cpp
int a, b;
cin >> a >> b;
char s[10];
cin >> s;
```

**ta如何处理空白字符**：

- 与 **scanf()** 一致
- 如果不想跳过空白字符，可以使用流控制关键词 **noskipws** （no skip white space），但只对单个字符有效（类似 **%c**）

```cpp
char c;
cin >> noskipws >> c;
```

注意：**cin** 对象属于命名空间 **std**，使用时要写成 **std::cin** 或者在文件开头加上 **using namespace std**

##### 1.2 cin.get() —— 读取单个或指定长度的字符（包括空白字符）

```cpp
char a, b;
char s[10];
 
// 读取一个字符，读取失败时返回0，多余字符残留在缓冲区（包括换行符）
a = cin.get();
 
// 读取一个字符，读取失败时返回EOF，多余字符残留在缓冲区（包括换行符）
cin.get(b);
 
// 在遇到指定终止字符（参数3）前，至多读取n-1个（参数2）字符
// 当不指定终止字符时，默认为换行符\n
// 如果输入的字符个数小于等于n-1（不含终止字符），则终止字符会残留在缓冲区待取，用以判断字符串是否已经读取成功
// 如果输入的字符个数多于n-1（不含终止字符），则余下字符将残留在缓冲区
cin.get(s, sizeof(s), '\n');
```

注意：**cin.get()** 在读取单个字符时，类似于 **fgetc()**，对空白字符的处理也相同，**cin.get()** 读取的字符也可赋值给整型变量

**cin.get()** 在读取指定长度字符时，类似与 **fgets()** ，但在换行符上的处理不同。他们都不会使换行符残留在缓冲区，但 **fgets()** 会将换行符也写进字符串，而 **cin.get()** 会丢弃缓冲区末尾的换行符

##### 1.3 cin.getline() —— 读取指定长度的字符（包括空白字符）

```cpp
char s[10];
cin.getline(s, sizeof(s));    // 第3个参数也可以指定终止字符
```

注意：**cin.getline()** 与 **cin.get()** 指定读取长度时的用法几乎一样。区别在于，如果输入的字符个数大于指定的最大长度n-1（不含终止符），**cin.get()** 会使余下字符残留在缓冲区，而 **cin.getline()** 会将输入流设为 **Fail** 状态，在主动恢复之前，无法再进行正常输入。

#### 2. getline()

**getline()** 并不是标准输入流 **istream** 的函数，而是字符串流 **sstream** 的函数，只能用于读取数据给 **string** 类对象，所以使用时也要

```cpp
#include<string>
```

如果使用 **getline()** 读取标准输入流的数据，需要显式指定输入流

```cpp
string s;
getline(cin, s);
```

注意：**getline()** 会读取所有空白字符，且缓冲区末尾的换行符会被舍弃，同时由于 **string** 对象的空间是动态分配的，会一次性将缓冲区读完，不存在残留

如果缓冲区开头就是换行符，则 **getline()** 会直接读到空字符串返回，不给键盘输入的机会，所以要先清理缓冲区

## 输出流

### C标准

**输出原理**：相应与输入流的 **stdin**，输出流也有一个 **stdout**，对应着命令行终端的的显示。此外，还有对应错误输出的 **stderr**，默认也是终端显示

**stdout** 也是行缓冲I/O，也有类似于 **stdin** 的数据同步：从用户程序到 **stdout** 的输出缓冲区，由用户程序决定；从 **stdout** 的输出缓冲区到终端显示，只有输出缓冲区末尾遇到换行符才会进行

#### 1. printf() —— 按照特定格式将stdout缓冲区的内容打印到终端

```c
printf("Number a = %d\n", a);      // 十进制整数
printf("Number b = %.2f\n", b);    // 浮点数，保留两位小数
printf("String s = %s\n", s);      // 字符串
```

注意：**printf()** 在一串字符中把要替换的内容写成格式控制符，从而形成格式化输出的效果

#### 2. puts() —— 将字符串和一个尾随的换行符写入到stdout的缓冲区，因此终端也会直接打印显示

```c
puts("hello");    // 立即输出hello并换行
```

#### 3. fputs() —— 将字符串写入指定输出流

输出流可以是stdout、stderr、文件流

stderr是标准错误流，是无缓冲的，会立即输出到终端

```c
fputs("hello world", stdout);    // 不会立即输出
fputs("hello world\n", stdout);  // 立即输出
fputs("hello world", stderr);  // 立即输出
```

#### 4. fputc() & putc() —— 将一个字符写入指定输出流

```c
char c = 'q';
fputc(c, stdout);
c = '\n';
putc(c, stdout);
```

#### 5. putchar() —— 将一个字符写入stdout

```c
char c = 'x';
putchar(c);
```

#### 5. fflush() —— 强制刷新缓冲区，将缓冲区的内容立即写到对应文件或设备上

**fflush()** 参数可以是文件流、stdout

```c
fputs("Hello World!", stdout);
fflush(stdout);
while (1);
// 在进入死循环前，会在终端打印“Hello World!”
```

注意：千万不要将 **fflush()** 用于 **stdin**，会导致不可预料的后果

### C++标准

#### 1. cout()

**cout** 是 **ostream** 类的一个实例，是行缓冲的

```cpp
char s[] = "hello world";
cout << "s: " << s << endl;
```

注意：插入 **endl** 对象时，将立刻清空输出缓冲区并显示，然后输出一个换行符

#### 2. cerr()

**cerr** 是标准错误流，也是 **ostream** 类的一个实例，默认输出设备为命令行终端，默认与 **stderr** 同步，是无缓冲的

```cpp
char s[] = "File open FAILED!";
cerr << "[Error] " << s;
```

#### 3. clog()

**clog** 也是标准错误流，也是 **ostream** 类的一个实例，默认输出设备为命令行终端。

和 **stderr** 不同的是，标准规定它是有缓冲的

```cpp
clog << "Failed!";
while(1){}
```

但是上面的代码却能正常输出，为什么呢？

注意：**clog** 标准规定它是带缓冲的，但具体的缓冲行为（如何时刷新）是由实现（编译器/库）定义的，并非严格统一

比如我运行上面代码用的是 **ubuntu的GCC标准默认库libstdc++**，它的一个关键设计是：**std::clog** 和 **std::cerr** 共享同一个流缓冲区，该缓冲区直接关联到 C 标准错误流 **stderr**。而在 Unix/Linux 系统中，**stderr** 被规定为无缓冲的。因此，尽管标准名义上说 **clog** 有缓冲，但 **libstdc++** 的实现让它继承了 **stderr** 的无缓冲特性，导致每次输出都立即写入终端

## 总结

在 C 中，建议使用 **scanf()** 进行格式化读取，用 **fgets()** 读取整行，用 **fgetc()** 或 **getchar()** 读取单个字符。

在 C++ 中，建议使用 **cin >>** 进行格式化读取，而 **cin.get()** 、**cin.getline** 、**getline(string)** 有各自的适用情况

标准输出相比输入来说较为简单，一般使用 **printf()** 或 **cout** 即可，也可以使用 **fmt** 库等来进行更多样化的输出
