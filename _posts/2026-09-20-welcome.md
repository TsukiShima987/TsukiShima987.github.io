这是用 Jekyll 搭建的第一篇文章，站点已经可以通过 GitHub Pages 访问了。

## 如何再写一篇

1. 在 `_posts/` 目录下新建文件，文件名格式必须是 `YYYY-MM-DD-标题.md`。
2. 文件开头写上 front matter：

```yaml
---
layout: post
title: "文章标题"
date: 2026-09-20 12:00:00 +0800
categories: 分类名
---
```

3. 保存后重新构建即可。

## 常用命令

```bash
bundle exec jekyll serve --livereload   # 本地预览，改完自动刷新
bundle exec jekyll build                # 只构建到 _site/
```
